Ethiopian Bahirehasab Calendar System

A C++ console application that supports:

Gregorian Calendar generation
Ethiopian Calendar generation
Gregorian ↔ Ethiopian date conversion
Bahire Hasab calculations for Ethiopian Orthodox holidays and fasting days
Developed as a group project for the Department of Information Systems at Addis Ababa University.
Features:
Gregorian Calendar  ,
Full yearly calendar display,
Single month display ,
Weekday calculation ,
Leap year handling ,
Ethiopian Calendar,
Full yearly calendar,
13-month support,
Ethiopian leap year calculation,
Weekday calculation,
Calendar Converter,
Gregorian → Ethiopian,
Ethiopian → Gregorian,,
Bahire Hasab
Calculates:

Nineveh  
Great Fast 
Easter 
Pentecost 
Ascension  
Apostles Fast 
Other Ethiopian Orthodox holidays 


Main Menu:
[1] Gregorian Calendar

[2] Ethiopian Calendar

[3] Calendar Converter

[4] Bahire Hasab

[5] Exit Program
